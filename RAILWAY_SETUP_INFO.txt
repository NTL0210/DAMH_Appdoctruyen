========================================
CÁC BƯỚC DEPLOY NHANH:
========================================

1. Truy cập: https://railway.app
2. Đăng nhập (dùng GitHub)
3. New Project → Deploy from GitHub repo (hoặc Empty Project)
4. Thêm MongoDB: New → Database → Add MongoDB
5. Thêm Backend service (nếu chưa có)
6. Cấu hình Variables (copy từ trên)
7. Generate Domain: Settings → Networking → Generate Domain
8. Test: https://YOUR_DOMAIN.railway.app/health

========================================
SAU KHI DEPLOY XONG:
========================================

1. Copy domain Railway (ví dụ: comic-api-production.railway.app)

2. Update Flutter app - Mở file: lib/data/services/comic_service.dart
   Thay đổi:
   static const String _baseUrl = 'https://YOUR_DOMAIN.railway.app';

3. Test API:
   - Health: https://YOUR_DOMAIN.railway.app/health
   - Comics: https://YOUR_DOMAIN.railway.app/comics?page=1
   - Docs: https://YOUR_DOMAIN.railway.app/api-docs
